# WORKSPACE — Squad 2's Blank Canvas

> This folder is **yours**. It starts empty — shape it however your research needs.

## How to Use

- Add your research, notes, and analysis here as new files.
- One topic per file, meaningful filenames (see [`../../docs/NAMING_CONVENTIONS.md`](../../docs/NAMING_CONVENTIONS.md)).
- Organize into subfolders only when it helps — don't create structure for its own sake.
- Never delete research — if something is superseded, mark it `[SUPERSEDED]` in a banner.
