## Solution Approach

IoT-based environmental sensor network using ESP32-C3 nodes for distributed sensing (temperature, humidity, air quality) with edge AI processing on Raspberry Pi 4B. MQTT mesh communication between nodes with NeoPixel visual alerts.

```
ESP32-C3 Sensor Nodes → MQTT → Pi 4B Edge AI → Dashboard + Alerts
                              ↓
                        NeoPixel Visual Alerts
```
