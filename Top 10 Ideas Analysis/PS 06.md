## Solution Approach

AI-powered crop analysis and farming recommendation system using camera-based disease detection and soil sensor data. Raspberry Pi 4B runs edge inference for crop analysis; ESP32-C3 interfaces with soil sensors; OLED display provides farmer-facing UI; NeoPixel alerts for irrigation and disease warnings.
