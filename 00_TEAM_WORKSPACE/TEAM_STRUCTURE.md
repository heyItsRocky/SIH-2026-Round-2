## Collaboration Rules

1. **Primary ownership:** Each squad owns its project workspace end-to-end (research → design → build → test → pitch).
2. **Cross-collaboration is allowed:** Members may help the other squad when needed — especially on shared technology (ULTRON, MQTT, edge computing, dashboards).
3. **Shared tech is everyone's:** Anything in [`03_SHARED_TECH/`](../03_SHARED_TECH/) is maintained jointly. Changes that affect both projects should be discussed.
4. **Decisions are team-level:** Major decisions (project direction, architecture, MVP scope) are recorded in [`DECISIONS/`](./DECISIONS/) — even if one squad made them.
5. **Communication:** Discuss major architecture changes before implementing. Record important decisions. Keep commits meaningful.
