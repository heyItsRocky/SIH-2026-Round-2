# MEETING_NOTES

> Lightweight meeting notes. One file per meeting.

## Convention

Name files like:

```text
MEETING_YYYY-MM-DD_TOPIC.md
```

Example: `MEETING_2026-09-08_Project_Selection.md`

## Template

```markdown
# Meeting — YYYY-MM-DD

**Date:** YYYY-MM-DD
**Attendees:** ...
**Topics:** ...

## Notes
- ...

## Decisions
- (link to DECISIONS/ record if one was made)

## Action Items
- [ ] Owner: task
```

## Rules

- Keep it short — notes are for the team, not for show.
- If a decision was made, record it in [`../DECISIONS/`](../DECISIONS/) and link it here.
- Don't duplicate research that belongs in a project workspace — link to it instead.
