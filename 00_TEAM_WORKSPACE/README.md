# 00_TEAM_WORKSPACE

> Team-level workspace — shared across both project squads.

## What Lives Here

| Folder | Purpose |
|---|---|
| [`TEAM_STRUCTURE.md`](./TEAM_STRUCTURE.md) | Squads, roles, and how we collaborate |
| [`MEETING_NOTES/`](./MEETING_NOTES/) | Notes from team meetings (one file per meeting) |
| [`DECISIONS/`](./DECISIONS/) | Decision records — the team's memory of *why* choices were made |
| [`SHARED_RESOURCES/`](./SHARED_RESOURCES/) | Team-wide strategy, methodology, and reusable resources |

## Rules of Thumb

- **Project-specific content** goes in the project workspace (`01_...` or `02_...`), NOT here.
- **Team-wide content** (applies to both projects) goes here.
- **Decisions** are recorded in `DECISIONS/` with a numbered format — never lose track of why an approach was selected or rejected.
- **Meeting notes** are lightweight: date, attendees, topics, decisions, action items.
